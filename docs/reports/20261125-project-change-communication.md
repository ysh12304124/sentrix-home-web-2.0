# 项目改动工作沟通说明

各位同事，本次已将基于最新主线的项目改进提交到 `yxw`，后续可以从该分支继续开展其他模块的验证和修改。主线基线为 `8c209ebc`，本轮主要完成视频处理、关键帧分组记忆和音轨转写关联，同时修复了测试中暴露的部分通用导入与问答问题。

视频处理目前已接通从原片导入、Katna 选帧、分组视觉理解，到转写关联、视频记忆保存及检索索引的流程。实际关键帧数量和每组大小沿用 SVD/Katna 的选择结果，画面分组按原片时间处理。每组保存描述、识别文字、标签、实体和对应帧列表，视频记忆保留各组与语音片段的依据。

视频与普通图片在同一工程中按素材类型和父子关系组织，共用资产表、存储及检索基础设施。普通图片保留自己的图片记忆，源视频保存视频记忆。关键帧作为视频的派生图片记录，关联父视频和原片秒数，并存放在视频派生目录中。搜索命中关键帧后，可以回到原视频对应位置，素材级评测按父视频归属去重。

编号方面，`video_id` 使用原视频的内部 `asset_id`，每张关键帧有独立 `frame_id`，通过 `parent_asset_id` 指向原视频。`group_id` 按“视频 ID + 组序号”生成，组内 `frame_ids` 保存有序帧编号。`audio_id` 标识视频音轨，`segment_id` 标识转写片段，两者均保留所属 `video_id`，片段还记录说话人标签、音轨起止秒数和原片偏移。算法组号 `selection_group`、展示组序号 `group_index` 和逐帧文件槽位分别保留，方便后续定位与核查。

测试过程中还修复了重复时间标签解析、拍摄地时区恢复、泛称人物导致的搜索拦截、检索首屏控制信息缺失，并补齐当前实例的离线地点数据。上述修改涉及共用导入和助手链路，需要其他模块同事继续关注普通图片、人物、邮件及文档、对话和引用交付的行为。

本轮已完成 10 个 ATM-Bench 原视频的完整构建和 10 道原始英文题评分，共产生 45 张关键帧、36 个分组。在相同本机模型、评分模型和配置下，修复前后答案均分从 `0.30/2` 提升到 `1.40/2`，正确视频进入候选的比例从 60% 提升到 100%，最终引用命中从 20% 提升到 40%。这些结果用于本轮小样本工程回归。324 项专项测试通过，发布整理后的工作树另复验 151 项通过。这批原视频均无音轨，音轨、说话人标签及时间偏移已通过单独的带音轨样片验证。

后续协作请重点推进以下工作。

- 检索与问答部分，继续检查正确候选的选择、最终引用，以及事件和地点范围的证据绑定。当前仍有 4 题未满分，10 个回合的证据状态仍为 `partial`。
- 地点解释部分，明确区分 GPS、附近居民点、行政归属和精确地标，避免将邻近城市名称延伸成机场、酒店等具体地点。
- 非视频功能部分，验证普通图片导入、人物姓名与别名、邮件和文档读取、对话续接、分页精读、跨相册范围和删除恢复。
- 工程检查部分，处理全量 CI 中既有的 lint、类型和方法可达性问题，并记录各模块的真实验证结果。

大家验证时请记录使用的提交、模型、数据范围和任务编号。功能细节、ID 示例及存储关系见 [视频功能修改说明](20261125-video-function-changes.md)，待修改项和测试复现命令见 [测试发现的其他待修改部分](20261125-other-module-test-followups.md)。
