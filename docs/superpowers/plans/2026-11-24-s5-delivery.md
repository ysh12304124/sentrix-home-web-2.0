# S5 交付记录（真事件索引与事件搜索）

日期：2026-11-24
分支：`feat/image-memory-v3`

## 索引

- 新向量命名空间 `event_document`（`domain/retrieval/scheme.py`），不复用观察/事件旧空间。
- `IndexEventDocument`：
  - 单图事件规范化文本与观察文本一致时，直接从观察 semantic 向量复制，**0 次额外嵌入**；
  - 多图事件按文档正文一次嵌入，进程内按文本 hash 去重；
  - 同时写权威向量与镜像索引；索引不可用只降级并留日志，不影响正文/时间线。
- 事件词法投影在 `event_documents.publish` 同一事务刷新：title/short/summary、内容条目、
  验证姓名与描述、真实地点、场景、成员日期、event_id；新版本发布先删旧词/旧 FTS。
- merge/dissolve 删除事件词法、authority `event_document` 向量并把旧 active 文档撤回；
  redirect 由 S4 的 merge 写入。

## 搜索

- `GET /api/v1/events/search`（注册在 `/events/{event_id}` 之前）：
  - 事件 FTS + `event_document` 向量两路；索引不可用时退回权威向量精确检索；
  - 返回 active 文档版本、matched_fields/evidence_refs、channels、score；
  - 展开文档真实全部成员，并单独标出本次命中的成员（content 命中才落到成员）；
  - redirect 目标事件可被解析，已撤回/非 active 文档不返回。
- 事件命中不重写成最后一张图的命中。
