## 导出包

固定三文件：`image_memories.jsonl`、`image_memory_provenance.jsonl`、`export_manifest.json`。

- 一张原生图片一条记录；`derived_kind/parent_asset_id` 的关键帧排除并计数。
- `id` = 文件名主干（可显式 id_map）；同一集合主干冲突 → `blocked` 快照，不写文件。
- 核心字段：type/image_path/timestamp（保留日期/月/年精度，不补午夜）/location/
  location_name/short_caption/caption(=detail，legacy 回退)/ocr_text/tags/entities/
  model_used/processing_version/processed_at。
- `location_name` 只取 asset_places 的真实地点；地址证据冲突时为空并标 conflict；
  视觉 scene 永不冒充真实地点。
- entities：观察实体 + 已确认人物姓名 + 未验证出现的稳定标签；内部 ID/证据在 provenance。
- provenance 每字段含 status/source/evidence_refs/observation_revision/build_id；
  `ocr_regions.status=not_provided, regions=null`，不用 [] 谎称已检测。
- manifest：schema/compat、scope/selection、计数与缺失率、时间/地点策略、ID 映射、
  文件 sha256、模型配置哈希、路径缺失/符号链接计数。

## API / 适配

- `POST /api/v1/memory-exports` 创建只读快照（scope/asset 范围、compat/strict_v3、id_map）。
- `GET /memory-exports`、`GET /memory-exports/{id}`、`GET .../files/{name}`；下载只接受
  快照清单内文件，blocked/缺失返回 409/404。
- `FileSystemMemoryExportWriter` 只写 data_dir/exports/{snapshot}，拒绝绝对/穿越文件名。
- PhotoBench 独立适配器 `photobench.infrastructure.image_memory`：校验 manifest 校验和、
  必备字段与 type，不改 GT/评分/轨迹导出。
