Sentrix 在 Apple M4 / 16GB、Qwen3.5-4B 4bit、并发16下，固定同64题两轮的QA吞吐从原参考 **2.257提升至3.462题/分钟（+53.38%）**，吞吐折算时间从 **26.58降至17.33秒/题（−34.80%）**。本PR修复MLX兼容与调度问题，加入有内存上限的精确前缀缓存，并提供调用、用量和缓存可对账的评测证据。
