# PhotoBench 双评分标准

本说明适用于当前双评分实现；旧题型评分协议见[历史说明](photobench-typed-evaluation.md)。
Agent始终开放式回答，同一份答卷可以只评一套标准，也可以同时评两套。默认只选开放式标准。

## 计分

| 标准 | 稳定ID | 单题评分 | 汇总 |
|---|---|---|---|
| 开放式回答（0/1/2 LLM as Judge评分） | photobench_open_v1 | 所有题由Judge对照参考答案评0、1、2，题型标签不覆盖所选标准 | 展示原始均分，满分2.00 |
| ATM-Bench式QS | atm_qs_v1 | 选择题由Judge盲匹配选项，再按答案键计0/1；数值题由Judge对照参考答案计0/1；列表计算Jaccard；开放题按ATM规则计0/1 | 全部QA逐题等权平均，以百分比展示 |

ATM选择题的匹配请求不传正确选项标记。选项缺少可区分信息时不能补猜；明确匹配other计0，
调用失败、格式错误或选项重叠待复核均保留未完成状态。数值匹配允许等值单位与等价日期写法。

列表分为返回集合与冻结GT集合的交集大小除以并集大小，按媒体类型与稳定标识去重。
真实空交付计0；交付或映射未记录时不可评分。新QS标准不使用any/all分支。
每道多轮QA只取冻结定义指定的评估轮计入总分，中间轮保留诊断，不增加总分权重。

合法0分属于完成。评分不齐时展示已评分均值和覆盖率，完整总分保持未完成；失败不当作0。
没有采集的标准固定显示“未运行采集”。历史混合评分通过独立读适配保留，不改写为新标准。
“ATM-Bench式QS”表示指标口径对齐，选择题和数值题采用Judge匹配，不能等同于官方榜单复现。
跨任务比较需要列出题集、规则版本、Judge、GT模式及覆盖率。

## 保存、补评与恢复

答题事实、公共诊断与标准评分分别保存。scoring_batches冻结规则、题目与答卷指纹、
提示词全文、Judge配置和GT依据；scoring_results按批次、QA与对话轮保存逐项结果；
scoring_summaries由后端统一汇总，列表、详情、导出与分析使用相同来源。

新测评与已有答卷补评都使用scoring_profiles和分标准scoring_configs，例如：

    {
      "scoring_profiles": ["photobench_open_v1", "atm_qs_v1"],
      "scoring_configs": {
        "photobench_open_v1": {"use_gt_images": true, "gt_metadata_mode": "image_metadata_v1"},
        "atm_qs_v1": {"use_gt_images": false, "gt_metadata_mode": "image_metadata_v1"}
      }
    }

补评可选择未评分、失败、待复核或全部，并预览QA数、对话轮数、评分项数。
同配置补评续写原批次，只处理选中范围内未完成的项目；修改提示词、Judge或GT配置会新建批次。
批次未覆盖的题保持未采集，不从其他批次拼接总分。补另一标准保留已有标准结果。
每次实际请求和响应留存，恢复未收到完整回执的请求会记录重试。

Agent断点恢复复用原相册、QA快照和答卷，只执行未执行的题目；评分失败走评分恢复。
旧run续跑保留冻结协议；旧未分类487题通过独立注册脚本保留原题与原标签，不自动猜题型。
执行版本统一归入同一任务，保留来源和各轮日志；“查看本轮日志”默认展开，可手动收起。
恢复接口及旧字段的兼容约定见[恢复说明](photobench-recovery.md)。

## GT与提示词

每套标准只有一个GT图片辅助开关，默认关闭。开启时逐张发送GT图片及紧邻的媒体标识、
拍摄时间和可读地点；关闭时这些材料均不发送。资料只给直接对照参考答案的Judge，
不传给Agent；选项盲匹配、列表Jaccard及公共诊断不增加这类GT输入。

可读地点来自独立审核映射，评分期间不调用在线地理接口；材料及映射版本冻结到批次。
图片已启用但读取或挂载失败时评分报错。时间或地点未记录会明确标示；
现存映射损坏或身份冲突会报错。辅助字段缺失不表示参考答案错误。
旧readable_v1和已冻结批次保持原协议。
生成方式、格式和逐图配对见[拍摄资料映射](architecture/photobench-gt-capture-context.md)。

提示词按标准与用途分别保存：开放式回答质量；ATM选择匹配、数值匹配、开放题判断。
任务行为和证据核验是独立公共诊断；相同配置下两标准共用结果。
列表展示只读公式和集合，不增加Judge调用。默认提示词修改不影响已启动任务。

## 检索及运行诊断

工具媒体召回率R@5使用最终回答记录中的有序候选，图视频联合排序、按类型和稳定标识去重，
有明确父视频映射的关键帧归到父视频，严格取前5份。汇总保留GT数量不超过5的范围，
同时列出纳入、超限排除和顺序/映射未采集题数；旧图片口径保留历史标识。
模型交付的媒体P/R/F1、全部工具候选覆盖率、图片/视频分项不进入QS。

配套产品改动保留拍摄时间来源和时区，不把未知时刻补为精确时间；
时间线、事件及检索按相应时间契约读取。地点行政归属与最近候选分别保存。
数据库保留main的文本向量与视频任务迁移，把拍摄时间迁移置于0018；
兼容已发布旧编号，按已知表结构校验，并使用同文件可重入连接锁处理嵌套读取。
