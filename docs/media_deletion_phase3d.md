# 素材删除第 3D 阶段

3C 清理通过后，服务按相册异步重建记忆。最终核验通过后，删除任务进入 `completed`，同一事务开启正常聚合写入并递增代次。

## 文件与迁移

| 文件或模块 | 改动 |
| --- | --- |
| `infrastructure/persistence/migrations/0032_media_rebuild.sql` | 建立生命周期、相册代次、任务和删除关联、推理缓存、处置记录、发布版本及索引清理记录共八张表。回填历史任务状态，将已满足清理条件的任务入队。 |
| `infrastructure/persistence/repositories/rebuilds.py` | 执行预检、证据取样与重建、原子发布、清理复核及最终完成。 |
| `infrastructure/media/rebuild_worker.py`、`bootstrap/rebuild_wiring.py`、`main.py` | 挂载服务生命周期中的后台执行器。 |
| `api/routes/deletions.py`、`repositories/deletions.py` | 提供入队、重试、状态查询及兼容原删除接口的生命周期字段。 |
| `database.py`、`application/media/model_generation.py`、`bootstrap/import_wiring.py` | 记录推理开始代次，在写入边界检查，并恢复正常聚合和文本索引。 |
| `summarize_event.py`、`build_graph.py`、`run_insights.py`、`extract_moments.py`、`family_graph_service.py` 及对应路由 | 将代次保护接入现有推理入口，线程池沿用调用方捕获的代次。 |
| `repositories/memory_graph.py`、`search_terms.py`、`moments.py`、`portraits.py`、`index_observation_text.py` | 支持事务内更新图和全文投影，校验人物瞬间来源、画像锁和文本向量版本。 |

## 调度、发布与恢复

- 清理成功后自动入队。客户端也可通过 `POST /api/v1/media-deletions/{deletion_id}/rebuild` 提交或重试，使用 `GET` 同一路径并带 `scope_id` 查询。
- 一个相册同一时刻由一个有效租约执行。多个删除任务合并到相册任务，保留各自删除 ID 和最终状态。重复提交已完成任务直接返回当前状态。
- 模型调用发生在 SQLite 写事务之外。发布核对租约、执行令牌、相册代次和证据快照哈希。新增或修改观察以及再次删除会令旧快照过期，并重新排队。
- 模型与向量缓存根据当前输入、模型标识和内容哈希复用。发布后的检查点允许服务恢复时继续核验外部资源。临时失败自动重试，阻塞状态持续预检，直到原因消除。
- 每轮发布只推进本轮有效的对象版本。旧锁定画像、旧派生投影和被撤销的结论继续受读取侧过滤。恢复正常聚合时再推进一次代次，暂停期间启动的推理也会被拒绝写回。

## 各对象的处理规则

| 对象 | 处理 |
| --- | --- |
| 事件 | 从当前可读观察、可确认的人物提及及拍摄时间生成标题、摘要和语义字段。没有观察支持的事件保持失效。拍摄时间语义冲突时阻塞。 |
| 人物和语义画像 | 从当前观察重建人物摘要、画像修订、语义画像和家庭画像。独立人工家庭画像与锁定修订受到保护。失去证据的锁定正文保持隐藏。 |
| 事实、关系和语义断言 | 保留 3B 已撤证的数据与审计。证据不足以重新确认的旧结论继续失效，并写入处置记录。家庭汇总从当前可读记录计算。 |
| 图与轮播 | 使用现有相册图构建器和事务内替换机制。轮播剔除失效事件和相应历史引用。旧问答材料继续受既有失效视图保护。 |
| 文本向量及全文 | 从当前观察和事件摘要构建投影，复用内容可验证的向量。正常导入写入 `text_vectors`，观察修订与代次保护写入。旧 Qdrant 事件投影按完整标识清理并保存进度。 |

## 最终完成条件

完成前复查 3B 检查点、3C 清理清单、永久墓碑、SQLite 源行和全文残留、Qdrant 投影、文件状态和共享文件当前所有者。已确认合法的外部及共享资源保留理由随清理记录可查。再核验派生对象处置、当前图谱版本和外键一致性。任何未解决的清理或归属冲突都会保留阻塞状态。通过时发布最终代次，解除相册聚合暂停，并唤醒空闲的相册后处理重试。

## 验收范围与限制

自动化验收覆盖图片和视频全流程、并发删除、共享人物和共享文件、3B 证据与审计保全、租约接管、索引故障重试、输入变化、晚到推理结果、历史隔离、锁定画像、正常索引恢复及最终状态幂等。API 到服务生命周期后台执行器的端到端测试使用临时 SQLite、Qdrant 和媒体文件，并以脚本模型验证编排。

已具备隔离测试环境端到端验收条件。真实相册、实际模型的摘要质量和大相册负载仍待验收。长事件或人物输入目前按单次推理提交，超出模型上下文时任务进入失败重试。跨相册证据归属冲突需要确认后才能完成。暂停期遗漏的人脸登记需要现有导入或人脸处理流程补做。3D 使用已存在的有效观察及关联证据。
