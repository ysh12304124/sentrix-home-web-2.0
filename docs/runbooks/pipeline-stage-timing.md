# 流水线阶段计时与GPU指标展示

流水线主顺序为媒体处理、事件总结、图谱与人物收尾；媒体准备并行、提交按输入顺序串行，视频处理嵌入对应媒体。收尾依次为参与者投影、记忆图（含因果判定）、家庭图谱、人物画像。

产品API的请求级StageTimings记录每个阶段的UTC起止、同一单调时钟下的相对起止、耗时、资产ID和终态。线程池显式传递请求上下文；源媒体准备只在源任务入口统计，关键帧记忆位于视频子阶段，避免重复归入源媒体准备。失败/取消关闭节点并保留状态，不吞异常。当前完成响应返回timing_spans，PhotoBench原样保存在pipeline_processing；全请求异常时不会返回成功响应，不能把内存中的节点声称为已持久化的完整失败轨迹。

各阶段_wall由最早实际开始至最晚实际结束计算，包含中间等待；原累计timings保留。收尾优先取直接测量的finalize_wall；历史仅有四段独立串行计时的情况保留原汇总。各子阶段可能重叠，禁止相加当总耗时。未采集节点的旧数据保留未记录，累计值只作为辅助说明。阶段结束后随主响应返回，当前没有新增实时节点流式接口。

Mac模型独立GPU数据缺失且整机峰值有效时，关键指标显示整机GPU占用（参考），说明包含其他应用、统一内存可能与进程内存重叠、不相加。独立值包含0优先；其他设备沿用模型GPU数据，均不改写原采样。

本次用户限定发布范围为8872；产品API8291/8191的采集改动仅提交待后续发布。8872部署后可接收新字段，但旧产品仍不提供完整阶段节点；不能称新采集已上线。

验证：前端614测试（原3项计时失败已修复），PhotoBench后端983测试，流水线/接收链专项138测试，Mypy113+6共119源文件，Ruff、类型/构建与模块依赖图通过。全部为隔离离线验证，无新增模型请求或QA。
