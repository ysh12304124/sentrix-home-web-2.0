# 推理模式上下文

开启reasoning时通过可选ReasoningChatModel端口创建独立客户端，普通回合继续使用共享客户端。
云端角色配置默认采用131072 token窗口；现役单端点云代理可用
SENTRIX_VLM_REASONING_CONTEXT_TOKENS=131072独立声明窗口，普通预算保持原值。
本地端点自报容量优先，目标窗口取声明值与实际容量中的较小值；未自报且未声明时沿用普通预算。
精确计数客户端保持/tokenize部署窗口合同。模型切换后重新装配时会重新探测容量。

推理回合的软压缩阈值改为新窗口的95%，输出上限和原有软限制执行策略保持。
128K是输入与输出共用的预算，预留原有输出及安全余量；请求不添加context_length参数，
不把max_tokens改成128K，也不修改模型原生thinking参数。

验证覆盖超过16K的输入、普通与推理并发、接近128K时触发压缩、16K/32K本地容量、
云角色请求选项、精确计数合同、持久执行器租约恢复。1008191额外保留普通16K运行合同。
