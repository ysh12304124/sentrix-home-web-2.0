# PhotoBench行为变更


## 2026-10-29 错误分析规则9

新增统一筛选聚合与固定快照取证接口，保留cases及旧报告。工具/原因/恢复改为同事件匹配；结束成功不推断错误恢复，证据缺失与服务错误分开。界面四视图共用筛选，导出改用筛选范围统计。AI新增全范围归纳、代表抽样、逐命题引用、单题失败隔离与同版本续跑。默认不发模型请求，不修改历史评分和GT。

## 2026-10-29 分类分析与分组图形

规则10用版本化能力与独立属性维度分析质量及执行问题；不把旧内容任务直接映射为能力。构成图的互斥/覆盖状态由逐对象成员集合判定，不根据汇总和猜测。未知/不适用保留，只有已确认分组使用环形图。类内满分率排除缺分，构成占比包括缺分，题与轮分别统计。冻结QA的漏存能力恢复只生成派生案例，有定义冲突或无快照时保留未知。无新模型请求、无评分策略变化，旧报告可读并标过期。
