# hpq 图构建在 2.0 的适配边界

来源：`ysh12304124/sentrix-home-web` 的 `hpq@a0b1ec1de0768a7415d7c407d247523c2a3d9c0a`。

## 保持的规则与链路

- 同源视频、最多后继两帧、30 秒窗口；跳过无意义变化。
- `rules_vlm` 只把关系变化且场景稳定的帧对送给文本模型；对象出现/消失本身不能证明因果。
- 判定结果写有向 `LEADS_TO` / `ENABLES`，保留置信度、理由和 `inferred` 来源；低于 0.60 的边不用于因果遍历。
- 图是按 scope 原子替换的派生物；模型不可用时普通记忆与其它图边保留，因果状态显式 `degraded`。
- 2026-11-10 修正因果判定提示词的 JSON 格式说明：旧提示中的 `{results: [...]}` 不是合法 JSON，本机 qwen35-q4km 曾在单帧对的批次请求和重试中均返回非法 JSON。现在明确要求单个对象、双引号字段名和完整行数；候选规则、判定阈值、失败降级与历史结果不变。当前运行中的服务需下次重启才会加载此修正。
- 旧版 keyframe builder 的同视频时序、对象/关系频次阈值与枢纽、关系 60 秒窗口、视觉 top-3/0.80/互选策略从 2.0 已落库的关键帧观察和权威视觉向量重建；不同视觉模型/维度不混比。
- 地点/日期上下文枢纽和 2.0 原有事件/观察/事实/实体边共同组成图。检索按问题类型和时序方向选边，仍由 2.0 primary 召回提供图种子，不替换回答提示词或生成器。
- 图效果 `source_consistency` 的参考边只从节点上的标准来源字段重建；故意删边/多边的测试分别使 recall/precision 下降。视觉相似和因果推断没有独立 GT 时不被伪装成可验真值。

## 与旧版数据模型的差异

2.0 强制 `VlmObserver` 保持固定观察字段，不接 bbox/空间关系 JSON；旧版 frame payload 的
对象框和独立空间关系列不能直接照搬。旧版 `CausalEdgeBuilder._extract_pair_signals` 自带
“无 bbox 时按两个共同具体物体、最多四个变化物体”回退；2.0 使用这条同源回退，
关系取自 `Observation.facts` 三元组。因而**有 bbox 才能发现的纯物体位移因果边暂不可判**；
不能把这类缺口记作“无因果”，须在评测报告中单列 `no_candidates`。补齐 bbox 需要先新增
独立端口和持久化信号，不得修改固定的 `VlmObserver` 响应契约。

2.0 的原生 `Event` 与视频派生 `Asset` 承担旧版 EVENT/SESSION/EPISODE 的层级职责，
不复制旧版节点类、Qdrant payload、frame/clip 检索器或独立的记忆生成器。这是架构映射，
不是旧版代码逐行复制。尤其没有 bbox 的纯位移因果边、旧版独立边标注 GT，以及
关键帧专用的词法重排细节，不能宣称数值与旧版完全等价；提交前必须按 2.0
文档门禁检查，并用真实数据集做外部回归。图指标若无独立 GT，只能标注为投影一致性。

## PhotoBench 图增益对照的历史 run 兼容

未绑定无图 run 的有图记录，只在相册、题集、模型和冻结的 QA 快照完全一致时，
自动选取运行时间最近且更早的完整 graph-off run。显式绑定始终优先；找不到
严格匹配时仍显示缺少对照，不把同名数据集或候选头当作无图最终媒体结果。

当 QA 题目已齐、媒体指标适用的题目集合相同且流水线完成，但 Judge/Agent
错误使 run 不是完整有效状态时，最终媒体召回率和精确率仍按列表页的交付口径
展示，标明是部分评分 run；质量分差值保持空值，不能把残缺评分当成完整对照。
这只改变报告读侧，不改历史 run 文件或产品问答链路。

## 2026-11-10 视觉证据效用选择

图检索启用且返回候选时，检索层把前六条普通候选与最多三条图候选交给
多模态视觉效用适配器，逐图询问证据是否有助于回答问题，读取首 token
`True` 的 logprob 排序，再交付最多六张。接口采用 llama-server 的
OpenAI 兼容 `logprobs`；它是论文原始 `True` logit 的归一化代理值，
并不宣称数值完全等价。图关闭时走原无图检索；非图片候选保留原位置，评分失败时沿用
原有图槽位结果，并在 channel trace 中记录降级。原图仅从 MediaStorage
端口读取，图片缩放在基础设施侧完成；原回答提示词与最终交付契约未改。
